👋 Almost ready!

This organizer isn't connected to its database yet. It takes about five minutes — open SETUP.md (it came with this file) and follow the numbered steps:

  1. Use your existing Firebase project (or create one).
  2. Add a Web app and copy the config values into the FIREBASE_CONFIG spot at the top of this file's script.
  3. Turn on Anonymous sign-in.
  4. Create a Firestore database and paste in the provided security rules.
  5. Reload this page.

Your tasks will sync privately to your own Firebase project — nobody else can see them.
